# crAPI Lab — Kali Linux

## 1. Navigate to the crAPI Folder

First, navigate to the `lab` directory and then enter the `crAPI` folder:

```bash
cd lab
cd crapi
```

## 2. Start crAPI

Run the following command to start all crAPI Docker containers in the background:

```bash
sudo docker-compose up -d
```

## 3. Access crAPI

Once the containers are running, open the following URL in your browser:

**crAPI Login:**

```text
http://127.0.0.1:8888/login
```

## 4. Access MailHog

MailHog is used to view emails generated by the crAPI application.

Open:

```text
http://127.0.0.1:8025/
```

## 5. Stop crAPI

When you are finished with the lab, stop and remove the running containers using:

```bash
sudo docker-compose down
```

> **Note:** `docker-compose down -d` is not required. The `down` command itself stops and removes the containers.
